# Rules for this repository

This repo is **public**, and it serves the live site on GitHub Pages. It holds
the Campaign Storyboard *program* only.

- **Never commit campaign content here**: no NPCs, secrets, sessions, lore,
  homebrew creatures, stat blocks or anything else from a real campaign. That
  includes content-seed scripts that write campaign data on load, and test files
  that contain it. Anyone on the internet can read every file and every old
  commit.
- Campaign content belongs in the owner's **private** saves repo, as a campaign
  or "everything" backup file the app loads through Backup → Load from GitHub /
  Load a file.
- History was rewritten on 19 October 2026 to remove campaign content. If your
  local clone is older than that, **delete it and clone again**. Do not merge or
  rebase old local commits onto `main`: that would put the removed content back.
