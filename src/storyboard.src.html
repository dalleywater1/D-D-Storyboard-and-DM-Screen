Send to Roll20

Roll20 doesn't let outside websites connect to a game, so the bridge is a small Mod script that runs inside Roll20. Mod scripts need a Roll20 Pro subscription. Scenes, places, items and lore become handouts; NPCs become characters, with their stat block, role and voice in the Bio. Everything arrives hidden from players.

Portraits: Roll20 doesn't let scripts upload pictures. On the NPC's page, click Download under the portrait, then drag the file onto the character's avatar in Roll20. If you installed the bridge before NPC stat blocks existed, paste the script again to update it.

  1. Install the bridge once In your game: Settings → Mod (API) Scripts → New Script. Paste the script, name it Storyboard Bridge, save.
  2. Copy your board as a Roll20 code
  3. Paste it into Roll20 Open the handout named Storyboard Import in your journal (the script creates it). Edit it and paste the code into GM Notes, replacing anything there. Save.
  4. Run the import Type !storyboard import in Roll20 chat. Run it again whenever you update the board; it updates the same entries instead of making copies.

Bring changes back

Edited text in Roll20? Type !storyboard export there, copy the GM Notes of the Storyboard Export handout, and paste it here.

      Backup & restore

      Your board saves itself as you go. A backup file is a copy you keep, or move to another storyboard.

      Everything

      Every campaign with its cards, pictures, GM notes, sticky notes and tabs, in one file. Use it to move your storyboard between the online and downloaded copies.

      One campaign

      A single campaign with its pictures, GM notes, sticky notes, tabs and DM Screen layout. Load it in any copy of the storyboard, or send it to someone.

      Load a file

      A campaign file or an everything file. You choose whether each campaign is added as new or updates the one already here. Nothing is removed.
